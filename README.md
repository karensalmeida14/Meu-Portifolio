
# Meu Portfólio Pessoal

**Aluna:** Karen Stefani de Almeida

## Descrição do Projeto

Este projeto apresenta meu portfólio pessoal, desenvolvido como parte das atividades do curso de Análise e Desenvolvimento de Sistemas.

O objetivo é apresentar meu perfil, meus projetos acadêmicos e disponibilizar informações de contato.

## Tecnologias Utilizadas

- HTML5
- CSS3
- Bootstrap 5
- JavaScript (Bootstrap Bundle)

## Estrutura do Projeto

O site possui três seções principais:

- **Perfil:** apresentação pessoal e objetivos profissionais.
- **Projetos:** apresentação de atividades desenvolvidas durante o curso.
- **Contato:** informações para contato.

O menu de navegação permite acessar as seções do portfólio. O Bootstrap auxilia na organização e responsividade do site.

## Recurso Novo Adicionado

Foi adicionada uma animação Hover nos cartões da seção de projetos.

Ao passar o mouse sobre os cartões, eles se movimentam levemente para cima e recebem uma sombra, tornando a navegação mais interativa.

## Implementação do Recurso Novo

A animação foi implementada utilizando CSS, com as propriedades:

- `transition`: cria uma transição suave.
- `transform: translateY(-10px)`: movimenta o cartão para cima.
- `box-shadow`: adiciona uma sombra ao cartão.

O efeito é ativado quando o usuário passa o mouse sobre os cartões.
